# Календарь звонков

Сервис, через который гость бронирует звонок с владельцем календаря. Термины пишутся по-русски в тикетах и интерфейсе; имя в скобках — то же понятие в коде.

## Участники

**Владелец** (`Owner`):
Единственный человек, чьё время бронируют; задан заранее и не регистрируется.
_Avoid_: Хост, администратор, пользователь

**Гость** (`Guest`):
Человек, который бронирует звонок с владельцем без регистрации.
_Avoid_: Клиент, посетитель, пользователь

## Бронирование

**Тип встречи** (`EventType`):
Вид звонка, который предлагает владелец: название, описание и длительность.
_Avoid_: Ссылка, услуга, шаблон встречи

**Бронирование** (`Booking`):
Занятый гостем интервал времени для конкретного типа встречи.
_Avoid_: Запись (глагол «записаться» допустим), встреча (вне «тип встречи»), резерв

**Окно бронирования** (`BookingWindow`):
Ближайшие 14 календарных дней, в которые гость может выбрать день для бронирования; сдвигается вместе с текущей датой.
_Avoid_: Окно записи, период, горизонт

**Слот** (`Slot`):
Интервал длительностью в тип встречи внутри окна бронирования, с которого может начаться бронирование. Слот **свободен**, если не пересекается ни с одним бронированием.
_Avoid_: Окно, ячейка, свободное время

## Страницы

**Каталог типов встреч** (`EventTypeCatalog`):
Страница, на которой гость выбирает тип встречи, чтобы начать бронирование.
_Avoid_: Страница записи, список услуг

**Предстоящие бронирования** (`UpcomingBookings`):
Страница владельца со всеми ещё не начавшимися бронированиями всех типов встреч.
_Avoid_: Предстоящие встречи, мои записи, расписание
